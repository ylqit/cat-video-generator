# 火山方舟镜头片段生产边界

运行时使用 Ark 标准 API：Seedream 可选生成单张 9:16 镜头锚点，Seedance 为每张镜头
卡生成一个 8～15 秒片段。V4 不使用强制故事板、固定三时段、长视频延展或逐镜兼容层。

## 输入模式

- `text_only`：只发送镜头 Prompt。
- `existing`：第一项发送用户批准的锚点，映射为 first frame。
- `generate`：先生成并人工批准锚点，再作为 first frame。
- 有开场锚点时最多再发送三项参考图；纯文本起步时最多发送四项。每项都必须由用户
  声明 identity/style/scene/prop/composition 职责，超过模型输入档案上限时在收费前停止。

## 任务恢复

Seedance 是异步任务。Task ID 持久化后，监看超时只暂停本地查询；刷新、服务重启和
“继续查询”均不重复 POST。创建结果未知且无 Task ID 时进入 `submission_unknown`，
只能从任务列表中选择候选对账。

Seedream 是同步图片接口，没有可查询的持久 Task ID。再次生成永远需要新的显式付费
确认，旧 attempt 和候选图片不会被覆盖。

## 区间重拍

单镜头内部编辑按 `@视频1 + @图片1 + @图片2`发送源视频和前后边界帧。Provider结果
落为候选，本地仅替换选区并映射原视频完整音轨。页面不会承诺区间外逐像素不变，只
说明区间外沿用原素材且精确合成可能产生轻微编码差异。最终版本必须人工观看批准。
