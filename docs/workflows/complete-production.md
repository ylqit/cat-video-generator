# 任意场景镜头片段完整流程

## 1. 项目与场景

创建项目只填写标题、第一场景标题、第一段原始剧本和可选图片。创建和编辑不会调用
Ark。项目可新增、删除和排序任意场景；“上午、河边、归家”等章节标签不参与校验。

## 2. 项目视觉档案

新项目从 Canon 建立一个不可变视觉档案 Revision，分别记录人物脸部/短发/5–7 岁体型、
灰白猫身份、画风正向/排除项、参考资产 ID 与内容 SHA。Web 可编辑并保存新 Revision，
也可恢复 Canon 默认；旧生成任务继续引用旧 Revision。`采茶叶.mp4` 只负责二维水彩、
自然柔光和茶园色彩，不把样片马尾人物写入角色身份。

## 3. 分阶段剧情创作

场景先保存用户原始剧情和补充口述。剧情医生结合项目角色、目标片段数和相邻场景提出问题证据
与保守/平衡/增强三档方案；人工接受后，剧本编辑生成一份尚未拆镜头的连续剧情。用户可编辑
全文，接受后写回当前 `sourceText`；原稿、LLM 原稿和人工接受稿都保留在 Step 审计中。

分镜导演只读取当前批准剧情。用户也可以在诊断阶段明确保留原稿并直接进入分镜，但页面会
清楚显示实际来源。每个阶段失败只记录本阶段，不回滚上一步接受稿。

## 4. 场景模式、造型与视频片段

场景选择单片段模式，或填写 2～6 个多片段目标数。AI 同时返回可编辑造型方案和严格
数量的视频片段；用户可修改服装、配件、猫咪外观、关键道具、标题、完整编号分镜与
8～15 秒时长，确认后才写入。每个片段只表达一个生活微事件，内部由 2～4 个连续子镜头
描述机位、主体空间关系、动作、人物配合、结果、运镜、收尾切点和声音。

猫咪是主要观察和行动对象，只执行自然四足动作；人物负责拿取、开合和穿戴等手部或
工具操作。没有明确剧情要求时，不给猫增加帽子、背包或复杂装备。

## 5. 场景视觉基准、首帧与参考素材

- `text_only`：Seedance 不接收图片。
- `existing`：用户选择一张已批准图片作为开场锚点。
- `generate`：Seedream 生成一张候选锚点，人工批准后才用于视频。

锚点方式和场景视觉基准策略是两个不同维度。每个片段另选 `off`、`appearance_only`、
`full_reference` 或 `derive_anchor`；默认 `appearance_only` 只继承共同造型并明确忽略视觉基准图
姿态、动作结果和构图。`derive_anchor` 先按“片段自定义 → 场景视觉基准 → 项目身份/画风”生成
开场锚点，批准后视频改用“锚点 → 片段自定义 → 项目身份/画风”，不重复发送场景基准。

造型、关键道具或人猫比例需要视觉确认时，系统建议场景视觉基准图，但不会阻断视频生成。
视觉基准工作台先保存服装、配件、道具、人物/猫咪姿态、构图、室内/户外变体和补充要求，
再按人物身份、人物体型、猫咪身份、画风、服装、道具和构图选择参考。最终 Prompt 只读
展示实际 `@图片1…N` 顺序与职责；缺少人物、猫咪或画风任一类别时，在付费前阻断。

场景视觉基准可生成、上传或从已批准图片选择。Canon 和场景基准的职责由来源锁定；通用上传图由
LLM 建议 `prop | composition | style` 后人工确认。系统最多
向图片生成发送 14 张、向视频生成发送 9 张；片段引用按“片段自定义 → 场景视觉基准 →
项目视觉档案”排序并按资产 ID、SHA-256 去重。视觉基准生成完成后在版本画廊中大图查看、
批准并选择、拒绝或切换旧版本；每个版本保留 Prompt 和输入快照。

## 6. 一片段一次生成

每个视频片段独立生成一次 8～15 秒 Seedance 视频。实际 Prompt、输入顺序、Task ID、
下载地址摘要、QC、SHA-256、抽帧建议和人工审核均可在右侧查看。整条重做只创建当前
片段的新 attempt，不影响其他片段。

长任务提交后立即进入应用级任务中心，编辑器和工作台不会持续等待或覆盖整页。用户可以关闭
视觉基准工作台、切换片段或切换项目；任务完成、失败、等待审核或待对账时统一通知，并刷新
对应场景/片段。服务重启后，进程内 Job 消失，但持久 Step 仍显示为“待恢复”，已有 Provider
Task ID 的任务只恢复查询，不重复付费提交。

片段编辑永远先保存。保存后 Web 再显示本次 LLM 创作分析的模型、候选图片和费用确认；
“仅保存”不会调用 Ark。选择分析时，LLM 查看当前及相邻片段和用户勾选的最多 9 张压缩预览，
返回素材适配、字段级修改与 Seedance 正文候选。用户勾选后一次应用；草稿已经变化时返回 409，分析失败不回滚保存。

最终 Prompt 分为人工确认的 LLM 创作正文和系统技术外壳。物理可行性、动作密度、空间关系、
节奏、声音与收尾均写在正文中；系统外壳只加入技术参数、长期角色/画风、真实图片编号/职责
和字幕、水印、分身等技术排除项。

批准视频后，本地 FFmpeg 从结尾附近选取变化最小且尽量靠后的帧，保存为可追溯
`shot_tail_frame`。下一片段可采用为唯一锚点；上一片段切换批准视频后，旧尾帧显示过期。

视频必须可播放、9:16、时长和音轨完整；剧情审美、轻微身份/画风差异、复杂动作和
道具风险只作为建议。AI 不会自动打回、改 Prompt 或产生第二次费用。

右侧固定分为“生成配置、实际参考图、锚点与视频版本、LLM 审稿与 Prompt”。实际参考图页可在
锚点/视频两个目标之间切换，逐张显示缩略图、`@图片N`、来源层级和唯一职责。版本页把运行中
尚无资产的任务与已有候选合并展示；旧输入生成的媒体仍可播放和下载，但批准或重新选择前必须
显式确认其可能与当前片段文字、时长、锚点或引用不一致。

## 7. 素材指代、总片与区间重拍

片段正文可以使用 `{{人物}}`、`{{猫咪}}`、`{{场景}}` 和 `{{道具:素材名称}}`。这些是 Web 内部
稳定名称，不会直接发送给 Provider。系统按当前真实输入顺序编译为 `@图片1…N`，并把人物、
猫咪、场景或道具指代写回相关子镜头正文。重新绑定素材会自动重排编号；未解析标记和不存在
的手写 `@图片N` 会在付费提交前失败。

人工批准的片段可按场景/片段顺序生成项目 EDL 和总片 Revision。每个边界默认硬切，也可选择
淡黑或 150～1000 毫秒短叠化；FFmpeg 同时处理画面和原生音轨，叠化总时长按重叠量扣减。

时间线按已检测边界映射编号子镜头，可一键预填“重拍子镜头 N”的文字和区间；边界不足时显示
估算标记并允许手工调整。片段时间轴允许选择 0.5～13 秒区间并生成候选版本。页面固定说明：

> 只重新生成选中区间；区间外沿用原视频素材。精确区间合成可能产生轻微编码差异。

新版本通过技术 QC 后仍需人工批准。完整片段选区建议直接重做片段；跨片段选区不得
作为一个模糊 Provider 请求提交。

## 8. 恢复

- queued/running 且有 Task ID：继续查询，不收费。
- submission_unknown：列出候选 Task，人工确认绑定，不重新 POST。
- failed/rejected/succeeded 后要重做：显式确认费用，创建新 attempt。
- 相同输入重复点击：复用原 Step。
