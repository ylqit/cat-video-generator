# 任意场景镜头片段完整流程

## 1. 项目与场景

创建项目只填写标题、第一场景标题、第一段原始剧本和可选图片。创建和编辑不会调用
Ark。项目可新增、删除和排序任意场景；“上午、河边、归家”等章节标签不参与校验。

## 2. 镜头卡

每个场景可手工添加镜头，或显式付费让文本模型给出建议。AI 只返回镜头标题、完整
导演描述和建议时长；用户确认后才写入镜头队列。完整描述应自然表达机位、运镜、主体
站位、动作路径、接触对象、结果、声音和稳定结尾，不再拆成几十个字段。

## 3. 锚点与参考素材

- `text_only`：Seedance 不接收图片。
- `existing`：用户选择一张已批准图片作为开场锚点。
- `generate`：Seedream 生成一张候选锚点，人工批准后才用于视频。

外部图片标注 `approved_anchor | generation_reference` 与
`identity | style | scene | prop | composition`，并选择用于锚点、视频或两者。系统最多
发送必要素材，不自动匹配或全量发送 Canon。

## 4. 一镜一片段

每张镜头卡独立生成 8～15 秒 Seedance 视频。实际 Prompt、输入顺序、Task ID、下载
地址摘要、QC、SHA-256、抽帧建议和人工审核均可在右侧查看。整条重做只创建当前镜头的
新 attempt，不影响其他镜头。

视频必须可播放、9:16、时长和音轨完整；剧情审美、轻微身份/画风差异、复杂动作和
道具风险只作为建议。AI 不会自动打回、改 Prompt 或产生第二次费用。

## 5. 总片与区间重拍

人工批准的镜头可按场景/镜头顺序生成项目 EDL 和总片 Revision。原片段保留原生音轨，
边界使用极短音频淡出/淡入。

单镜头时间轴允许选择 0.5～13 秒区间并生成候选版本。页面固定说明：

> 只重新生成选中区间；区间外沿用原视频素材。精确区间合成可能产生轻微编码差异。

新版本通过技术 QC 后仍需人工批准。完整镜头选区建议直接重做镜头；跨镜头选区不得
作为一个模糊 Provider 请求提交。

## 6. 恢复

- queued/running 且有 Task ID：继续查询，不收费。
- submission_unknown：列出候选 Task，人工确认绑定，不重新 POST。
- failed/rejected/succeeded 后要重做：显式确认费用，创建新 attempt。
- 相同输入重复点击：复用原 Step。
