## 2. 任务与公共接口

- [x] 角色设计接口立即返回 `JobDto`，失败原因可由任务中心读取。
- [x] 分组 compile/run 按阶段顺序执行，只运行到下一个人工审核门。
- [x] 分组解组会归档配方并保留业务对象；转分镜组与批量下载有真实处理器。
- [x] 所有付费任务保留幂等键、预计费用校验和进程内串行门。
- [x] 所有接口覆盖并发版本冲突、重复提交和失败恢复测试。

- [x] 儿童、猫咪、同框比例以三个 `CharacterDesignNode` 显示。
- [x] 动态故事、角色图、镜头、锚点、视频和导出产物追加在对应阶段区域。
- [x] 每种节点点击后打开真实局部控制台，或展示准确禁用原因。

## 4. LibTV 式前端交互

- [x] 移除 `recipeExpanded` 和全宽 `RecipeInspectorPanel` 聚合入口。
- [x] 分组框支持整体选择、移动和清晰的选中边界。
- [x] 分组工具条提供：整组执行、加入工具箱、转分镜组、解组、批量下载。
- [x] 节点局部控制台自动定位并做视口边界避让。
- [x] 点击空白关闭局部控制台；Space 平移保留选择；Esc 按层级退出。
- [x] 缩放较小时只降低节点细节，不把分组折叠回聚合节点。
- [x] 键盘焦点、44px 点击区域、非颜色状态和减少动画通过静态与组件测试检查。

## 5. 六阶段业务验收

- [x] 一句话创意可补全、编辑、审核；未审核不能生成故事。
- [x] 固定生成三个治愈故事候选，人工批准后锁定 EpisodeRules。
- [x] 三类角色图片均选择并批准后才允许进入分镜。
- [x] 分镜支持从故事、从角色和手工编写，并满足 8–60 秒拆镜边界。
- [x] 锚点、视频、技术 QC、语义诊断和逐镜审核完整串联。
- [x] 成片合成验证原生音轨；最终审核后可导出 MP4 和批量 ZIP。
