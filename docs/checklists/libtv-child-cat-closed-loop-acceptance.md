# LibTV 式一人一猫固定 IP 闭环验收

更新时间：2026-08-24

## 验收原则

- [x] 实施、测试和构建全部单进程顺序执行，不启动并行代理或并行服务。
- [x] 不以模拟 Provider 结果替代真实 Seedream/Seedance 黄金样片结论。
- [x] 未接通的 LibTV 工具必须展示禁用原因，不创建伪任务。
- [x] 所有付费调用必须先展示估价并由用户确认；无法精确计量时明确显示“付费调用·暂未计量”，仍要求显式确认。

## 1. 节点交互与视觉

- [x] 工具条固定锚定在选中节点上方，局部控制台固定锚定在节点下方，二者中心线与节点一致。
- [x] Space 平移、滚轮缩放和节点拖动通过 `requestAnimationFrame` 每帧最多写入一次坐标，移动期间不查询节点 DOM 或调用 `getBoundingClientRect()`。
- [x] 悬浮内容保持屏幕可读尺寸，不随 Vue Flow 缩放变小。
- [x] 节点移出视口时工具条和浮窗同步离开，节点返回时同步返回，选择状态保留。
- [x] 控制台始终位于节点下方，不翻转、不贴边；空间不足时允许随节点移出视口。
- [x] 浏览器窗口缩放后重新测量画布容器并维持节点锚定关系，不把浮窗限制到安全区域。
- [x] 点击空白关闭；点击另一节点切换；Space 平移保留选择；Esc 分层退出。
- [x] 文本控制台为 660×320，图片为 760×440，视频为 860×480，分镜为 760×420，并在小视口安全收缩。
- [x] 页面不再将节点类型名、对象类型或内部状态作为主要标题。
- [ ] 新节点锚定浮窗语义下的 1440×1024、1920×1080、1280×720 截图回归。

### 1.1 语义编排、流光连线与全局 Space 平移

- [x] 后端为全部画布业务节点投影唯一的 `layoutHint`，覆盖 canon、creative、story、character_scene、storyboard、render、export 七条语义泳道。
- [x] 固定儿童、固定猫咪、线条材质按稳定 itemOrder 进入 Canon 输入列，`StylePresetNode` 不再落入默认末尾列。
- [x] 前端按真实节点 footprint 计算列宽与纵向间距；完整整理按语义顺序重排，新增未保存节点只寻找无碰撞位置。
- [x] 已保存或人工移动过的节点在后台投影刷新时保持原位置；仅后端标记为未定位的新节点执行自动落位并保存布局版本。
- [x] 分组框在成员布局完成后根据成员真实边界重算，保留标题与阶段导航空间。
- [x] 自定义 Edge 具备基础线、流光线和 20px 透明命中线；选中节点只激活其直接入边/出边，单线悬停只激活当前边。
- [x] `prefers-reduced-motion` 下停止流光滚动，仅保留静态高亮。
- [x] 持久化的普通参考、构图与媒体引用可剪断；Canon、审核门、六阶段主流程和系统派生血缘返回锁定原因。
- [x] 剪断走真实删除接口并令下游保持过期审计；8 秒撤销使用独立创建请求重建原连接，不伪造清除 stale 状态。
- [x] Space 平移由画布主区域捕获阶段控制器统一拥有；空白、分组框、Canon 预设和普通节点区域均可启动平移。
- [x] Space 平移期间禁用节点/分组拖动、选择和连接创建，并通过 pointer capture 保持拖出原元素后的连续性。
- [x] 输入框、文本域、下拉框、按钮、链接和 contenteditable 保留 Space/Delete/Backspace 的原生输入语义。
- [x] 控制台采用标题、中部唯一纵向滚动区、常驻底部操作区三段结构；外壳不再与内容形成嵌套滚动。
- [x] 剧情策划控制台展示创意摘要、固定 Canon 依赖、三案规则、执行过程、阻塞原因及后端声明的真实动作。
- [ ] 在真实浏览器中完成节点流光、鼠标位置剪刀、分组/预设区域 Space 平移和 1280×720 底部操作区人工复核。

## 2. 可恢复节点移除

- [x] 右键菜单提供“从画布移除”，Delete/Backspace 在非输入焦点下执行同一归档动作。
- [x] 后端通过 `availableActions` 声明可移除权限与禁用原因，前端不猜测业务保护规则。
- [x] 活跃六阶段骨架、固定儿童/猫咪 Canon、批准故事、被下游使用的批准媒体受到保护。
- [x] 归档只过滤画布节点、关联显示边与分组可见成员，不删除业务对象、资产或历史版本。
- [x] 归档与恢复使用 `If-Match` 更新布局版本，并写入持久的投影变化事件。
- [x] 成功归档后提供 8 秒撤销入口，恢复后重建原节点、边与业务状态投影。

## 3. 节点动作与分镜

- [x] 每种 CanvasNodeType 点击后打开真实控制台、执行真实动作或显示明确禁用原因。
- [x] 删除 enabled 但无处理器的动作分支。
- [x] `from_story` 使用已批准故事和 EpisodeRules。
- [x] `from_characters` 只接受已批准儿童和猫咪槽位，并继承 Canon identity。
- [x] `manual` 不调用付费模型，保存为新分镜版本。
- [x] 三种入口均进入“确认镜头—准备资产—合成提示词”，且不能自动批准。

### 3.1 剧情脚本与服务端 Prompt 编译

- [x] 创意简报、剧情脚本和分镜脚本继续分别使用 `StoryBrief`、`StoryRevision + EpisodeRules + scenes[]`、`Scene + ShotBeat + TemporalBeat`，未新增重复剧本模型。
- [x] 批准故事在画布中显示为“剧情脚本定稿”，并作为唯一主执行分支；未批准候选继续作为历史分支保留。
- [x] 剧情脚本定稿投影包含完整梗概、EpisodeRules、稳定 `sceneKey`、连续性规则、换场原因和版本状态。
- [x] 故事批准事务内幂等创建或更新动态场景规划；旧故事场景保留并标记为过期，不删除历史资产。
- [x] “角色生成分镜脚本”已更名为“基于固定角色补充分镜”，并明确不得绕过剧情审批。
- [x] 分镜三步页不再在浏览器拼接最终 Prompt，而是调用 `POST /api/v2/projects/{projectId}/storyboard-prompt-compilations`。
- [x] 服务端按 Canon、本集造型、所属场景、镜头/时间节拍、视频运动与声音、排除项分层编译，并返回引用职责、警告、阻塞项、估价和输入哈希。
- [x] 编译结果复用 `PromptRecord` 持久化，并在输入与已物化镜头一致时绑定 `ShotBeat.prompt_id`。
- [x] 缺少当前批准 Canon-v3、本集三个角色设计槽位、Scene Look、必要道具或场景版本过期时，拒绝编译或锚点生成。
- [x] 分镜人工批准要求所有镜头都已绑定当前编译 Prompt；上游版本变化后旧 Prompt、锚点、视频和序列按版本门禁失效。

### 3.2 事件方案、剧情脚本扩写与画布任务可视化

- [x] 新组合包将“AI 剧情生成”拆成事件方案生成、事件选择、剧情脚本扩写和剧情脚本批准四个子步骤，不再把短事件候选误作完整剧情脚本。
- [x] 事件方案使用独立的 `story_event_candidates` 持久化，保存儿童行动、猫咪参与、小变化、温暖收尾、场景建议、猫咪模式、评分、候选序号和来源批次。
- [x] 每次事件生成固定产出三个候选；选择新事件会令旧选择变为 `superseded`，未选择事件时禁止扩写完整剧情脚本。
- [x] `StoryRevision.source_event_candidate_id` 记录完整剧情脚本的事件来源；旧项目不伪造事件记录，并通过只读“旧版剧情直出”节点保持兼容。
- [x] 事件生成和剧情脚本扩写分别使用持久 Worker 操作与独立接口，立即返回任务句柄，并继续执行幂等、估价和人工门禁。
- [x] 只有被选择的事件连接剧情脚本主链路；其他候选保留为低优先级历史分支，不驱动角色设计、场景规划或分镜。
- [x] 画布节点 `executionScope` 按 canvasNode、businessObject、scene、shot、operation 和 phase 精确匹配，禁止同一 Recipe 的无关任务串到当前节点。
- [x] 父任务可以聚合声明范围内的子任务；没有命中父任务时，不会仅因 Recipe 相同而吸附无关子任务。
- [x] 可执行节点本体直接展示排队、运行百分比、等待审核、成功、失败、Provider 状态和结果摘要，无需先打开控制台。
- [x] 节点控制台展示完整任务时间线、父子进度、耗时、错误、恢复入口和产物摘要，不再静默截断为五条记录。
- [x] Worker 任务事件补充 businessObject、scene、shot、parentStep、childStep 和 Provider 状态，任务投影与画布产物刷新继续使用同一持久状态源。
- [ ] 使用真实运行中的事件生成和脚本扩写任务，人工确认节点状态在 SSE 到达后 2 秒内更新，并在成功后静默出现三个候选与剧情脚本产物节点。

## 4. 固定 IP、画风与媒体

- [x] Canon 身份不能被角色设计图或普通参考素材替代。
- [x] 角色设计图只承担 appearance、pose、scale、composition。
- [x] 新组合包固定使用 Canon-v3，并要求 `person:headshot`、`person:fullbody`、`cat:front`、`cat:side`、`style:line_texture` 五个槽位。
- [x] Canon-v3 锚点请求只提交一套 `style:line_texture` 风格证据，不再混入 `style:indoor/outdoor`；旧项目继续保留原 Canon 版本。
- [x] `style:line_texture` 只承担线条、材质和光照职责，Prompt 明确排除叶片、露珠、绿色配色、微距构图和身份改写。
- [x] 视频 Prompt 只描述动作、表情、运镜和声音，不重写身份与画风。
- [x] 每镜执行技术 QC、6–8 帧语义诊断和人工审核。
- [x] 支持整镜重做、0.5–13 秒片段重拍和带理由人工覆盖。
- [x] 最终音画包含可播放原生音轨并完成最终人工审核。

### 4.1 角色素材库与显式 Canon 预设

- [x] 创建新组合包后直接投影固定儿童、固定猫咪和线条材质三个真实节点，不再依赖聚合 Recipe 节点表达 Canon。
- [x] 儿童节点显示面部与全身比例证据，猫咪节点显示正面与侧面证据，画风节点显示线条材质证据。
- [x] `SubjectReferenceDto` 投影包含 semanticKey、标题、内容/缩略图 URL、审核状态、SHA-256 与必需标记。
- [x] 素材与预设库包含角色库、风格库和最近使用；角色卡按真实证据槽位展示，不伪造表情、背面或多角度占位图。
- [x] “应用至画布”复用现有二进制资产，同时创建或复用版本化 Subject、SubjectReference、画布节点、分组成员和身份/画风血缘边。
- [x] Canon-v3 必需槽位不可在本集视觉档案中删除、换绑或改变职责。
- [x] 修改本集视觉档案创建新版本，不改写全局 Canon，并只失效相关角色造型、场景、Prompt、锚点、视频与成片资产。
- [x] 内容与生成节点不再显示重复媒体工具条；图片、视频成品节点继续保留 LibTV 式媒体工具条。
- [x] 专用视觉证据编辑器展示真实缩略图、编号、职责、版本和锁定状态。

## 5. 动态场景与视觉资产链路

- [x] 故事场景使用稳定 `sceneKey` 和版本化 `SceneContinuityRules`，旧故事可从 `mainScene/environment/timeWeather` 合成单场景规则。
- [x] 8–15 秒只允许一个场景；16–60 秒的场景数不得超过 `ceil(总时长/15)`。
- [x] 第二个及后续场景必须填写换场叙事目的，不满足时拒绝保存故事候选。
- [x] 故事批准后立即按实际剧情场景动态创建 `SceneNode`；分镜确认后再按实际镜头补齐资产，不预建固定空场景或提前生成全部图片。
- [x] 场景资产就绪状态由已接受且未过期的资产计划、已批准绑定资产和已批准 Scene Look 派生，不建立第二套进度状态。
- [x] 必需槽位覆盖本集服饰、环境，以及故事规则声明的装饰和核心道具。
- [x] 分镜三步流程的“准备资产”读取真实场景就绪状态，并可直接打开对应 `SceneNode` 控制台。
- [x] 场景控制台复用现有资产规划、上传/生成、版本选择和 Scene Look 工作台。
- [x] 缺少服饰、环境、装饰、道具或 Scene Look 时，禁止合成逐镜 Prompt、生成锚点和视频。
- [x] Scene Look 草稿、选择或上游场景规则变化时，下游锚点、视频和序列标记为过期，历史资产保留。
- [x] 室内/户外 Scene Look 由当前场景规则派生，逐镜只绑定所属场景的环境和道具。
- [x] 动态场景与资产门禁专项测试通过：前端 3 项、后端 22 项。
- [ ] 完成原创单场景、两场景和多镜头真实付费样片验收。
