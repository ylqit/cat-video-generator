# LibTV 式固定悬浮节点控制台验收清单

> 状态约定：`[ ]` 未验证，`[x]` 已通过，`[-]` 已实现但受外部环境阻塞。

## 1. 固定尺寸与节点映射

- [x] 简报、故事、审核和普通文本节点使用 `760×360px` 预设。
- [x] 图片生成、角色设计、参考图和图片资产使用 `920×560px` 预设。
- [x] 视频资产和片段重拍使用 `1040×560px` 预设。
- [x] 分镜导演使用 `1120×620px` 预设。
- [x] 未专门适配节点使用 `720×320px` 预设。
- [x] 视口小于 `1280px` 时，控制台限制为视口宽度减 `24px`、视口高度减 `96px`。
- [x] 内容超过固定尺寸时仅在控制台内部滚动，不改变画布布局。

## 2. 屏幕固定与锚定行为

- [x] 选中节点时按节点位置初始化一次控制台坐标。
- [x] 节点 DOM 暂不可测量时使用安全屏幕位置，控制台不会出现“点击无反应”。
- [x] `Space + 拖动`平移画布后，控制台 `left/top` 保持不变。
- [x] 画布缩放和节点拖动不会重新锚定控制台。
- [x] 节点上方工具条继续按节点位置更新，节点离开视口时可隐藏。
- [x] 切换节点时创建新的定位会话；窗口缩放时只限制越界，不回到节点附近。
- [x] 点击空白或按现有 `Esc` 层级退出时关闭控制台并清除选择。

## 3. 控制台外壳与内容

- [x] 控制台使用 `position: fixed` 覆盖画布，无遮罩且不压缩画布高度。
- [x] 移除统一的 `SELECTED NODE` 高占用标题栏。
- [x] 全屏按钮由外壳提供，标题、状态和操作由具体节点内容负责。
- [x] 简报节点显示主题、时长、画幅、受众、情绪、阻塞原因、任务进度和真实动作。
- [x] 通用节点显示结构化详情、输出摘要、任务状态以及后端声明动作。
- [x] 未声明处理器的动作不会伪装为可执行操作。
