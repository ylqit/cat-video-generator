# Sowii 公开资料证据边界

参考资料：

- 虎嗅 / Founder Park：《红杉高瓴投资，前美团民宿 CEO 联合伯克利教授，做了一只 AI 蘑菇》
- https://www.huxiu.com/article/4871864.html

该资料是采访整理，不是 Sowii 生产系统的技术审计。本项目只能借鉴其中公开表达的产品原则，不能据此虚构技术实现。

## 文章明确表达的内容

- 用户关注的不是互不相关的视频，而是同一个角色连续发生的生活。
- 今天的状态和经历会影响明天发生的内容。
- 当前 App 被描述为生活视频流，一天大约出现 8 到 12 个片段。
- 文章使用“生成、编排、分发”描述内容流的组织。
- 文中将目标系统概括为规划、模拟、渲染三层。
- 规划层回答角色为什么行动，模拟层让环境变化，渲染层将内部状态转为可消费内容。

## 属于公司设想或研发方向的内容

- “十万段甚至更多”出现在条件式设问中，不是已经预生成十万条视频的事实证据。
- 效用函数、数学建模和强化学习被描述为正在探索的路径，没有公开生产接口和效果评测。
- Civilization Model 是目标架构描述，文章没有证明三层已经全部成熟上线。
- 文章没有公开具体模型供应商、Prompt、数据库、任务队列、缓存、视频库存规模或主体一致性方法。

## 本项目允许借鉴

- 用同一组持续存在的角色组织所有内容。
- 为角色保存记忆、关系、物品和未完成事件。
- 在生成视觉内容前先决定“为什么今天发生”。
- 将日期、天气、地点、节日、道具和人工审核的外部内容信号作为世界输入。
- 将故事规划、连续性状态和视觉渲染拆成不同边界。

## 本项目不采用

- 不复制 Sowii 的角色、场景、口头禅、具体事件或视觉识别。
- V1 不建设 24 小时仿真社会、强化学习行为系统或每用户独立数字生命。
- 不把大量预生成最终成片当作日更系统的前提。
- 不将无限画布当作必要架构。V1 使用结构化表单、时间线和审核列表即可。

## 对本项目的降维映射

| Sowii 公开概念 | 本项目 V1 |
| --- | --- |
| 规划层 | 可选 LifeChapter、DailyLifePack、EpisodeSpec |
| 模拟层 | WorldState、ContinuityEvent、日期天气与外部信号 |
| 渲染层 | 已批准主体参考、按需 Seedream 场景关键帧、身份质检、Seedance 视频 |
| 生活流 | 每天早、中、晚三段视频 |
| 长期记忆 | 只追加的连续性事件台账 |

该映射是本项目的工程设计，不代表 Sowii 的真实内部实现。
