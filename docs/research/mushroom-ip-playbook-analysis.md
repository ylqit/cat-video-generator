## 1. 文章来源与性质界定

  与 git 历史中的 `docs/research/sowii-evidence.md`（采访整理的原则层资料）性质不同。
- 标题"月入4万"为营销口径；"4 条作品 / 84 万粉丝 / 起号不到两个月"为作者声称，
  未独立验证。
- 价值定位：它提供了**可复制的最小生产工作流**（宫格故事板法），恰好补上
  sowii-evidence.md 缺失的执行细节，可与本仓库的 L1-L5 分层模型对照。

## 2. 文章全文要点拆解

### 案例数据（作者声称）

- 账号"小蘑菇的秘密日常"：仅发布 4 条作品，收获 84 万粉丝；最早一条视频距今
  不到两个月。几乎条条作品几十到几百万点赞。

### 变现模式

- 核心主线：**数字潮玩、IP授权 / IP衍生品**。
- 品牌商单：零食 / 饮品 / 文创 / 母婴 / 家居等**软萌、治愈向**品牌，与账号定位契合。
- 星图平台同品类报价：单条视频最低 5 位数起。

### 工作流三步

**第一步：出镜 IP 形象设计**
- 推荐 Image2 生图模型（平替：NanoBanana、豆包、即梦）。
- 提示词框架（XXX 替换为目标形象，如"小竹笋"）：
  > 3D超写实毛绒IP角色设计，拟人化XXX形象，强情绪治愈纯色背景**站立三视图**，
  > 治愈系软萌气质。小小的眼睛，胖嘟嘟的脸，超反差的五官，超写实毛发，
  > 毛流感细腻蓬松，皮克斯级渲染，8K超高清晰度，细节拉满。

**第二步：宫格故事板 → Seedance 2.0 一键生成视频**
- 围绕 IP 做衣食住行叙事。方法：**先根据 IP 生成宫格故事板**（多格漫画式
  分镜图），再把宫格故事板上传到有 Seedance 2.0 的工具，一键转化为视频。
- 具体操作：用内置 Image2 的工具（LibTV / 星流AI / Lovart 等）上传人物图，
  提示词示例："围绕@图片 IP形象，帮我设计一个@图片 人物制作水果挞的
  **宫格故事板**。治愈系，风趣，动作俏皮"。
- 视频提示词："将宫格故事板转化成视频，**不添加字幕和BGM**（统一不加，
  方便后期处理以及多故事生成）"。
- 时长策略：**30-50 秒**，可设计多个故事板，把做水果挞、外出交友、购物等
  生活片段组合在一起。

**第三步：剪映剪辑成片**
- 所有片段导入剪映，添加同款经典背景音乐/字幕，调整细节导出。

## 3. 与 sowii-evidence.md（原则层）的对照

| 维度 | sowii 采访资料（原则层） | 本文（执行层） |
|---|---|---|
| 核心主张 | 同一角色连续发生的生活；今天影响明天 | 固定 IP + 衣食住行题材框架 |
| 架构 | 规划/模拟/渲染三层（目标架构，未证明全落地） | 无架构：生图→故事板→视频→剪辑 |
| 连续性的来源 | 角色记忆、关系、物品、未完成事件（状态台账） | **没有任何世界状态/连续记忆机制** |
| 内容组织 | 一天 8-12 个片段的生活流 | 30-50 秒单条多片段组合 |

**关键观察**：该玩法的"连续剧感"完全来自固定 IP 形象 + 题材框架，
不依赖任何跨条状态。这反向印证了本项目"日更世界状态"（事件冷却、
道具台账、跨天状态摘要）的差异化——我们做的是 sowii 原则层描述而
该玩法没有做的那一层。

## 4. 与 AIGC 平台对比文档（L1-L5）的对照：宫格故事板是 L3 的第三条路线

本仓库 `docs/research/aigc-short-drama-pipeline-comparison.md` 归纳的 L3 镜头层
通行做法是"逐镜头关键帧 → 逐镜头 i2v → 剪辑"；本项目方案 C 是
"逐镜头分段 + 真实尾帧链接"。本文的宫格故事板法构成第三条路线：

| | 逐镜头 i2v（行业主流） | 分段+尾帧链接（本项目 multi_clip） | 宫格故事板（本文） |
|---|---|---|---|
| 一致性机制 | 每镜头参考图/首帧锚定 | 上段真实尾帧=下段首帧，切点零漂移 | **所有镜头共享同一次生图**，风格/角色/道具天然一致 |
| 单镜头可控性 | 高（逐镜头把关） | 高（逐段 QC） | 低（格子内部由模型自行解读） |
| 生成次数 | N 镜头 = N 次视频 | N 段 = N 次视频 | 1 次生图 + 1~2 次视频 |
| 时长上限 | 单镜头 4-15s，剪辑拼长片 | 段 4-15s，拼接 8-15s | 30-50s（模型对宫格的整体转化） |
| 主要风险 | 切镜漂移 | 段间跳切、链路复杂度 | 格子边界 artifact、模型不理解宫格语义、单格画质受限 |
| 人工关卡 | 每镜头关键帧审核 | 段级 QC + 可选首帧审核 | 故事板一张图审核（把关点最少） |

**判断**：宫格法用"空间换时间"——把多镜头一致性从视频模型的时序问题
转化为生图模型的单图问题，对 30-50s 的轻叙事 IP 视频是成本与一致性的
甜点位；但单镜头动作精度、物理连续性（本项目的可见世界内核所管的事）
在宫格法中完全交给模型自觉。本项目 12s×3/天、含交接/包含等高风险物理的
场景仍适合分段+链接；宫格法可作为未来"长合集内容"（周更 30-50s 精华版）
的候选路线记录。

## 5. 对本项目的可借鉴清单

1. **三视图提示词实践**：蘑菇 IP 的形象图就是"纯色背景站立三视图"——
   佐证本项目 L2.3 三视图 Canon 方向是 IP 行业的通用做法。
2. **生成不加字幕/BGM、后期统一加**：与本项目 L4 合成层职责划分一致
   （本项目保留原生环境音、不用 BGM，属定位差异而非缺陷）。
3. **内容形态差异记录**：蘑菇账号 30-50s 单条多片段 vs 本项目 3×12s/天
   日更窗口——定位不同，不改动；但"多故事板组合成长合集"可作为未来
   内容形态的备选。
4. **画风定位差异**：蘑菇 IP 是 3D 超写实毛绒（皮克斯级渲染），
   本项目目标是 2D 绘本插画——提示词框架（形象+气质+背景+三视图+画质词）
   结构可借鉴，风格词必须整体替换。
5. **变现定位参考**：数字潮玩 / IP授权 / 治愈系品牌商单——供运营层参考，
   不影响技术架构。
