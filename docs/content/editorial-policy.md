# 外部信号与编辑政策

## 目的

外部信号让角色生活与现实节奏保持联系，但不能成为角色世界的控制层。固定 Canon、已经交付生效的状态、当天背景、可选 LifeChapter 和安全规则始终优先。

## V1 允许的数据来源

- 日期、星期、节气和公开节日。
- 经产品确认的天气数据。
- 运营人员手工输入的主题。
- 运营人员提交的小红书公开视频或评论页面链接。
- 用户明确提供且允许用于本项目分析的内容。

V1 不自动爬取小红书，不使用私人账号登录态批量采集，也不绕过页面访问限制。

## 人工选链加 AI 提炼

每条外部内容经过以下步骤：

1. 运营人员提交来源 URL 和使用原因。
2. 系统或编辑者提炼抽象信号：
   - `theme`
   - `emotion`
   - `audienceNeed`
   - `lifeSituation`
   - `visualMotif`
   - `expiresAt`
3. 删除用户名、头像、账号 ID、联系方式和非必要个人信息。
4. 默认不保存评论原文和视频文件。
5. 编辑者确认信号与本项目受众、世界和原创边界相符。
6. 批准后生成 `TrendSignal`，仅供故事规划器读取。

## 原创转换规则

允许：

- 将“周一不想起床”转为“猫咪把晨光藏进被角”的原创情境。
- 将“社交电量耗尽”转为“两个主角一起寻找安静云朵”的绘本隐喻。
- 聚合多条评论共同反映的情绪需求，不保留个人表达。

禁止：

- 按原视频的动作顺序、镜头节奏和结尾复刻。
- 复制评论原句作为字幕、标题或角色口头禅。
- 仅更换人物和猫咪外观，保留原作品主体结构。
- 使用用户隐私、健康状况、现实冲突或可识别经历作为娱乐素材。
- 以 Sowii 作为标题、关键词或角色设定吸引流量。

## 信号有效期

- 普通情绪或生活信号：默认 30 天。
- 节日和突发热点：不得晚于事件相关窗口。
- 长期常青需求：经编辑重新归类后进入常青主题库，不保留原来源内容。
- 过期信号不能自动续期，需重新审核。

## 内容安全

任何候选包含以下内容时直接拒绝，不允许通过 Prompt 弱化：

- 暴力、伤害、强迫、羞辱或死亡拟态。
- 危险模仿行为。
- 医疗、金融、法律或心理诊断建议。
- 对真实个人、群体或品牌的负面影射。
- 无授权的第三方角色、商标、音乐或画面。
- 需要大量文字解释才能成立的误导性情节。

## Canon 审批

- 故事生成器只能产生 `canonProposals`。
- 编辑者必须确认该变化不会破坏长期故事空间。
- 批准后才写入 `ContinuityEvent(scope=canon)`。
- 外部信号不能直接产生永久 Canon。
- 删除或反转既有 Canon 必须新增 `retire` 或 `replace` 事件，不能修改历史记录。
