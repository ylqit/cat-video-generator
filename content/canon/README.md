# 连续性事件台账

生产实现使用本目录下的 `events.jsonl` 保存已批准并应用的 `ContinuityEventV1`。

规则：

- 一行一个完整 JSON 对象。
- 只追加，不修改或删除历史行。
- `scope=day` 记录已经进入正式交付包的当日事实。
- `scope=canon` 必须在内容冻结时预先批准，并在包含该 Episode 的交付包成功后追加。
- 候选、审核失败、生成失败和未交付内容不得写入台账。
- 更正历史事实时追加新的 `replace` 或 `retire` 事件。
- 仓库初始阶段不创建虚构的已交付事件；真实首日交付后再生成 `events.jsonl`。
